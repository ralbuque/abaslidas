# Abas Lidas – Modo Gravação

Extensão para Chrome e Brave que ajuda a não se perder entre dezenas de abas durante uma gravação.

Clique em **"Estou pronto para gravar"** (ou use **Alt+Shift+G**). Todas as abas da janela ficam
com o favicon trocado por uma **bolinha vermelha numerada**. Quando você clica numa aba, a marca
some. Assim fica fácil ver o que já foi lido e o que ainda falta.

## Instalação

1. Abra `brave://extensions` (ou `chrome://extensions`).
2. Ative o **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação** e escolha esta pasta.

## Atalhos

- **Alt+Shift+G** — marca todas as abas como não lidas
- **Alt+Shift+L** — limpa todas as marcas

Os atalhos podem ser trocados em `brave://extensions/shortcuts`.
